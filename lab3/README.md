# Лабораторная №3 — приближение функций (интерполяция)

Streamlit-отчёт с пошаговыми выкладками и графиками (`matplotlib`). В `homework_lab3.py` у ключевых функций в docstring указаны ссылки на лекции и номера формул из курса.

## Что реализовано

| Пункт | Содержание |
|--------|------------|
| **2** | Узлы «таблица 1» (неравноотстоящие): многочлен **Лагранжа**, **Ньютон** по разделённым разностям (47)–(49); контрольные точки из задания; сравнение с \(f(x)\). |
| **3** | Узлы «таблица 2» с шагом \(h=1\): **первая формула Ньютона** (прямые разности \(\Delta\), формула (46)), **вторая формула** (обратные разности \(\nabla\) от последнего узла); для контроля — та же запись через (49) с переставленными узлами. |
| **4** | **Линейный сплайн** по таблице 1; коэффициенты на отрезках; погрешность в контрольных точках. |

**Функция по заданию:** \(f(x)=\sin x + x\).

**Параметры** \(g\) (подгруппа) и \(k\) (группа) задают сдвиг узлов вида \(g-2k\) в формулировке лабораторной; вводятся в интерфейсе.

Дополнительно в UI есть демонстрация **Лагранжа по таблице 2** (равноотстоящие узлы) — для наглядности, отдельно от пунктов 2–4 методички.

## Файлы

| Файл | Назначение |
|------|------------|
| `homework_lab3.py` | Лагранж, разделённые разности, Ньютон (вперёд/назад для равного шага), линейный сплайн, узлы и контрольные точки. |

## Запуск локально

Из каталога `lab3`:

```bash
python3 -m venv venv
source venv/bin/activate   # Windows: venv\Scripts\activate
pip install -r requirements.txt
```

Дальше — либо скрипт:

```bash
chmod +x run_local.sh
./run_local.sh
```

либо вручную:

```bash
streamlit run homework_lab3_ui.py --server.port 8503
```

Откройте в браузере адрес, который покажет Streamlit (обычно http://127.0.0.1:8503).
